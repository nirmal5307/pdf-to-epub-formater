# Inkbound Wiki

**Inkbound** turns PDFs into reflowable **EPUB3** files for e-ink readers (Kobo, Kindle, BOOX, PocketBook, Xteink, and more).

This wiki is a short guide. Full details live in the [README](https://github.com/nirmal5307/pdf-to-epub-formater#readme).

## Try it in 3 steps (Codespaces)

**No install. No Python commands.**

1. Open **[Create Codespace](https://codespaces.new/nirmal5307/pdf-to-epub-formater?quickstart=1)** (any GitHub account works).
2. Wait for the Codespace to finish loading (first time can take a few minutes).
3. When it’s ready, Inkbound **starts automatically** and opens on port **8765**.

Drop a PDF → pick a reader profile → convert → download your EPUB.

Full guide: [[Codespaces]]

> Prefer fully offline / private? Use [[Local-Install]] instead — Codespaces runs in the cloud.

## What Inkbound does

- Local web UI + CLI PDF → EPUB converter  
- Reader profiles: Universal, Kobo, Kindle, BOOX, Compact  
- Typography controls, e-ink image pass, optional OCR  
- Smart chaptering (TOC / Part / “How to…” when possible)  
- EPUB3 + NCX for wide sideload support  

---

## Language support

**English-first today.**

- UI is in English  
- Chapter detection is tuned mainly for English books  
- Book language + OCR language pickers already support many locales  
- **More UI languages and better non-English chaptering are coming soon**

Want to help with another language or send freely licensed test PDFs? See [[Contributing]].
