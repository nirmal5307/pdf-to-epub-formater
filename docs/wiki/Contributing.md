# Contributing

Inkbound is early and **English-first**. Help is very welcome.

## We’re looking for

- **More languages** — UI translations; chapter words (“Chapitre”, “Kapitel”, “Capítulo”, …)  
- **Test data** — public-domain / freely licensed PDFs that stress chaptering, covers, OCR, columns  
- **Device photos** — converted EPUB on a real Kobo / Kindle / BOOX / Xteink  
- **Reader feedback** — margins, fonts, CSS quirks on your device  

Please **do not** upload copyrighted commercial books to issues or the wiki.

## How to help

- Open an [issue](https://github.com/nirmal5307/pdf-to-epub-formater/issues)  
- Or a pull request — see [CONTRIBUTING.md](https://github.com/nirmal5307/pdf-to-epub-formater/blob/main/CONTRIBUTING.md)  

Thanks!
