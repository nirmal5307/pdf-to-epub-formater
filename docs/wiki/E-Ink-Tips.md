# E-ink tips

- Pick a **reader profile** (Kobo / Kindle / BOOX / Compact) before converting.  
- Text PDFs convert best; use **OCR** for scans.  
- If a cover looks cached on device, remove/re-add the EPUB.  
- English chapter detection is strongest today; other languages are improving.  
- After converting, sideload the `.epub` like any other book.

Device-specific feedback welcome on [[Contributing]].
